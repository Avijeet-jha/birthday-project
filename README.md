# Neha Birthday Surprise 🎀

A casual, interactive React + TypeScript + Vite + Tailwind birthday website for Neha.

It intentionally avoids a romantic feel and does not require Neha's personal photo.

## Run

```bash
npm install
npm run dev
```

## Included

- Random birthday/celebration images
- Casual friendship-focused copy
- Funny memories
- Tiny "catch the 🎀" game
- A playful "Message From Neha" reveal
- Click-to-open friend messages
- Final birthday surprise
- Optional music toggle
- Responsive mobile layout

## Personalize

Most content is in `src/data/birthdayData.ts`.

You can change memories, messages, captions, random images, Neha facts and the final message.

## Music

Put an MP3 at:

`public/music/birthday-song.mp3`

Music starts only after the user clicks the music button.
